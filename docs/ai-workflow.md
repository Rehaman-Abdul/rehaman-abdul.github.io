# AI-Assisted Workflow

| Task | Best tool | Example prompt |
|---|---|---|
| Code generation & refactor | GitHub Copilot (editor) | "Add a keyboard-accessible lightbox to the work grid, no libraries" |
| Layout & component ideas | Claude / ChatGPT | "Suggest three hero layouts for an instructional designer; describe wireframes" |
| Case-study writing | Claude | "Interview me with 10 questions about this project, then draft a case study in the 11-section template" |
| Summarising project decks/docs | Microsoft Copilot (Word/PowerPoint) | "Summarise this deck into problem, approach, results with numbers" |
| Copy variants | ChatGPT / Claude | "Give 10 headline options, 8 words max, plain language" |
| Accessibility review | Claude + axe/WAVE | "Review this HTML for WCAG 2.2 AA issues and give fixes" |
| SEO | Claude / ChatGPT | "Write unique title (≤60) and description (≤155) for each page" |
| Updates | Copilot | "Add a new project card matching the existing markup" |

## Rules
1. You own the facts — never let AI invent metrics, clients or quotes.
2. Give AI your real context (audience, tone, constraints) and paste real code.
3. Review generated code; run Lighthouse/axe after each change.
4. Don't paste confidential employer content into public AI tools.
5. Keep your voice: edit AI copy until it sounds like you.
