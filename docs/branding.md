# Personal Branding Strategy

## Positioning
**Learning experience designer who pairs instructional rigour with visual craft.** You are the rare designer who can write the objectives, storyboard the module, design the visuals, build it and cut the video — one person, one coherent experience.

## Value proposition
> I turn complex content into clear, beautiful, measurable learning — covering strategy, instruction, visuals and video, so teams get one accountable partner instead of four vendors.

## Brand statements (pick one, test, keep)
- "I design learning people actually finish."
- "Where learning science meets visual craft."
- "Complex ideas, made clear, made memorable."
- "Instructional design with a designer's eye."

## Visual identity
| Item | Choice |
|---|---|
| Palette | Ink `#0E1116`, Paper `#F7F5F0`, Teal `#0B8F84` (dark mode `#2DD4C4`), Highlight `#FF7A59`, Muted `#5B6472` |
| Alt palettes | Navy `#1B2A49` + Gold `#E0A526` (corporate) · Plum `#4B2E83` + Mint `#7AE7C7` (creative) |
| Type | Fraunces (headings, editorial warmth) + Inter (body, clarity). Alt: Space Grotesk + Source Sans 3 |
| Icons | Lucide / Phosphor line icons, 1.5px stroke, rounded caps |
| Shape | 14px radius cards, generous whitespace, one accent colour per page |
| Imagery | Real project screens, mockups in device frames, behind-the-scenes storyboards |
| Motion | Subtle reveal and hover lift; respect `prefers-reduced-motion` |

## Design-system rules
1. Max two typefaces, three weights. 2. One primary CTA per section. 3. Contrast ≥ 4.5:1. 4. 8px spacing grid (tokens in `assets/css/tokens.css`). 5. Every project card leads with an outcome, not a tool.
