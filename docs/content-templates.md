## Project card / description formula
**[Project]** — For [audience], I [what you did] using [method/tools], resulting in [measurable outcome].
Example: *Onboarding Reimagined* — For 400 new hires, I redesigned a 3-hour lecture into a 45-minute scenario-based module in Storyline, cutting time-to-proficiency by 30%.
